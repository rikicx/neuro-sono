# Neuro-Sono

Conceito de repaginação do site da Clínica Neuro-Sono, desenvolvido em Vite e preparado para publicação na Vercel.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

O build final é gerado em `dist/`.

## Publicação na Vercel

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Node.js: 22

O arquivo `vercel.json` já contém essa configuração.

## Conteúdo

Os dados institucionais, contatos, endereço, exames e artigos foram baseados no site público da Neuro-Sono. Informações clínicas adicionais devem ser confirmadas antes da publicação definitiva.
